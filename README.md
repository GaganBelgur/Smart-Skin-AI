# Smart Skin Disease Detection App (On-Device AI)

## Overview

Smart Skin Disease Detection is an Android application that uses On-Device Artificial Intelligence to analyze skin images and identify possible skin conditions without sending sensitive patient data to the cloud.

The application is designed with a privacy-first architecture where image processing and AI inference happen entirely on the user's device, enabling:

* Offline functionality
* Fast predictions
* Enhanced privacy
* Reduced cloud dependency
* Lower operational costs

This project serves as a practical implementation of On-Device AI using Jetpack Compose, CameraX, and TensorFlow Lite.

---

## Problem Statement

Healthcare organizations require a mobile solution that can:

* Capture skin images using a smartphone camera
* Detect possible skin conditions locally on the device
* Work without internet connectivity
* Ensure patient data remains private
* Deliver low-latency predictions
* Minimize cloud infrastructure dependency

Example conditions include:

* Acne
* Eczema
* Psoriasis
* Fungal Infection
* Melanoma Risk Assessment
